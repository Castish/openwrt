# Лицензии

Сохранены SPDX и LICENSE*/RUNNER-LICENSE/AUTH-LICENSE исходных этапов.
Linux и локальные C80 kernel-драйверы распространяются под GPL-2.0-only;
в Linux userspace ABI действует Linux-syscall-note. Самостоятельные ARM
пробы/загрузочные помощники и auth-инструменты сохраняют свою указанную
лицензию MIT/GPL из соответствующего снимка. При отсутствии отдельного SPDX
применяется лицензия содержащего исходного выпуска.

Оригинальные LICENSES.md описывают также исторические личные бинарные
сборки. В этой публичной публикации их закрытых firmware, персональных
данных и runtime-ключей нет. Наличие собственного GPL-драйвера не означает
разрешения распространять проприетарные OEM blobs. OpenWrt пакеты и upstream
зависимости сохраняют собственные лицензии/исходные URL в пакетных манифестах.

# Состав публикации

Публикуются54 исходных снимка,2052 исходных файла/скрипта/конфигурации,
полные доступные патчи Linux и восстановленная история этапов. Хеши
оригинальных исходников позволяют сопоставить этот Git с личным архивом.
Общие результаты аппаратных проверок изложены без сырых UART/SSH-логов.

В публичный Git не экспортируются:

- персональные Dropbear/SSH-ключи, c80-auth.cpio и файлы shadow;
- полный NOR/TPOS, PROFILE/RADIO, калибровка, сырые сетевые пакеты;
- заводские закрытые firmware/bootloader-бинарники и образы с ними;
- личные ZIP-релизы, бинарные оракулы, инструменты/кэши/окружение и raw hardware logs.

CRC/SHA256 и адреса публичных аппаратных регистров в исходниках не являются
дампами устройства. Синтетические MAC/IP тестовых фикстур — часть тестов.
Ключи подписи официальных пакетов и их хеши относятся к upstream-проверке,
а не к личной идентификации SSH. Текущая схема публикации проверяется
`python3 tools/check-public-tree.py` перед записью коммитов и push.

История импорта создана20 октября2026UTC по сохранившимся снимкам;
даты/сообщения новых Git-коммитов не выдаются за исходную историю разработки.
Полная аппаратная работоспособность очередной версии отмечается только
после проверки на роутере; программный PASS не заменяет эту проверку.

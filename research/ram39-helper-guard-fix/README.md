# RAM39 helper guard fix1

В исходном комплекте RAM39 helper ошибочно ожидал
`6.12.113-c80-openwrt-ram39-bmc-profile`, хотя ядро называется
`6.12.113-c80-openwrt-ram39-gtk-init`. Это ошибка упаковки нашего комплекта.
Данная отдельная поправка сохраняет строгое сравнение версии и исправляет
только ожидаемое имя. Исходный архив RAM39 остаётся неизменным.

Исправленный helper размещается во внешнем initramfs поверх встроенного.
Его размер увеличен с 4096 до 8192 байт; в DTB меняется только initrd-end.
Все прежние личные ключи Dropbear и /etc/shadow сохранены побайтно.
Ядро, драйвер, firmware, калибровка и handoff прежние. Это **не исправление
повторного WPA2-подключения**: в RAM39 оно пока не работает на устройстве.

После сохранения аппаратного отчёта и Finished в корень личного TFTP можно
скопировать `c80-auth-helper-fix1.cpio` и `c80-openwrt-ram39-helper-fix1.dtb`,
а последним заменить `c80-start.txt`. Прежние kernel и handoff включены
для полноты. Обычный reboot через LAN1 SSH загрузит тот же RAM39 без ручного sed.
Проверка: `cat /etc/c80-helper-fix`, затем `uname -r`.
SSH root@192.168.0.1 / openwrt; SSID C80-RAM39, пароль openwrt123.
Для отката восстановите старый c80-start.txt; старые payloads сохранены.

15 новых проверок на реальном ARM QEMU загрузили этот внешний CPIO,
сверили установленный helper, его права и владельца, все три серверных ключа
и пароль, выполнили настоящий version guard с правильной и неправильной
версией и воспроизвели отказ исходного helper. Положительная проверка
намеренно завершается до запуска MCU/сервисов, используя существующий
once-directory. Полный AP start и физические MCU/DMA/RF здесь не проверяются.
Прежние 3753 native cases наследуются по неизменному образу ядра; заново
их и 43 прежние QEMU проверки для этой однострочной поправки не запускали.

Архив содержит личные серверные ключи. В публичный Git входят только наши
исходники и обезличенное описание проверок. Для воспроизводимой сборки
нужен локальный персональный комплект RAM39.

В публичном снимке отсутствуют персональные payloads, ZIP и runtime логи.

# uboot-native-netboot-v1

Сохранённый исходный снимок промежуточного этапа порта Archer C80 v1 RU.
Состав и хеши оригинальных исходников: SOURCE-MANIFEST.json.
Импортирован в Git из сохранившихся файлов20 октября2026; первоначальной
Git-истории в рабочем каталоге не было. Состояние проекта и подтверждённые
аппаратные результаты описаны в ../../docs/HISTORY.md.

Это исходники и исследовательские скрипты. Готовые образы, закрытые заводские
бинарники, персональные SSH-ключи и сырые логи устройства сюда не входят.
Исходные сборочные скрипты сохраняют исторические зависимости и пути облачной
среды; перед запуском ознакомьтесь с ../../docs/BUILD.md.

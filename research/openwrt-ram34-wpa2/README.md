# RAM34: WPA2-PSK/CCMP через штатный hostapd

RAM33 подтвердила на плате повторное подключение открытого клиента. RAM34
добавляет RSN/CCMP, передачу EAPOL до авторизации, BMC STA и установку GTK/PTK
через формат WTBL-команд MT7626. IP разрешается после ключей и авторизации
hostapd. RX проверяет аппаратные ошибки и возрастающие CCMP PN по TID;
идентичная повторная установка ключа не отправляет MCU-команду и не сбрасывает PN.

**Первый аппаратный тест RAM34 ожидается.** Пройдены3576 native ASan/UBSan
сценариев, включая101 новый security case;13 трасс настоящих OEM ARM builders.
В32МиБ QEMU штатный подписанный hostapd выполнил31 проверку: неверный MIC
отвергнут, M3 MIC/GTK wrap и установленный TK сверены независимым клиентом,
правильный M4 авторизует порт, повторное подключение сохраняет AP. После
авторизации прошли13 проверок настоящего Linux/DHCP/ARP/IP/TCP. Установка ключа
в QEMU синтетическая: RF, MCU, аппаратное CCMP и DMA не эмулируются.
[Пределы проверки](VALIDATION.md).

Тестовый SSID C80-RAM34, пароль Wi-Fi openwrt123, один клиент, канал6/CCK,
MTU1400. ПК получает192.168.2.2/24, AP192.168.2.1. c80-wifi start использует
hostapd/nl80211 и явно присоединяет AP к netifd перед DHCP. c80-wifi status
показывает GTK/PTK/authorized и счётчики без ключей/PN. После проверки — stop,
дождаться Finished, затем report. AP stop/start в том же boot требует reboot.

GTK rekey отключён, групповой Ethernet передаётся как PTK-unicast единственному
клиенту. WPA1/TKIP, PMF/WPA3, несколько клиентов,5ГГц/HT/VHT, операторский kick
и полная UCI wifi up интеграция не реализованы. Физическая совместимость нового
WPA2-пути пока не подтверждена. Образ остаётся RAM-тестом без новой записи NOR.

Полный патч Linux6.12.113 содержит31 файл; ram33-to-ram34.patch — отличие RAM33.
DMA pool668112 байт и старые смещения сохранены. Ethernet/DSA/UART/restart,
DMA scheduler, все OEM firmware и45 подписанных пакетов не менялись.
verify-all-native.sh запускает общие и security сценарии; build-qemu.sh строит
отдельный software-peer kernel, который не предназначен для роутера.

Наши rootfs-шаблоны в overrides/. Общая сборка — ../../docs/BUILD.md.
Персональные образы, CPIO/SSH-ключи, OEM binaries, калибровка и сырые аппаратные
логи в Git не публикуются. Оригинальные собственные исходники сохранены
побайтно и перечислены в SOURCE-MANIFEST.json. Личный архив остаётся в рабочей
области; для других устройств нужны собственные calibration/SSH inputs.

# License and provenance

This is a personal configuration bundle for the user's own Archer C80.
It intentionally includes unique private SSH server keys inside c80-auth.cpio
and the user-selected root password hash. It is not a generic public image.

Local auth-overlay build and verification scripts are MIT licensed; see
AUTH-LICENSE. They add no runtime kernel or bootloader code. qemu-bootshim.bin
is the24-byte test-only ARM entry shim generated by build.sh; not used on C80.

The unchanged hardware zImage and handoff come from the previously supplied
c80-openwrt-ram31-scheduler.zip (SHA256
805cd14bac690f3d4945c48d1cbd99ef09b8a7fcb74fe2e95fe997dd6f041479).
That source/build release contains the complete local C80 changes, rootfs
and build configuration. All361 frozen files have been verified unchanged.
The matching package/source/license list is copied as parent-openwrt-packages.json;
OEM firmware origins remain in parent-FIRMWARE-SOURCES.json. Its OEM firmware
is a private transformation of the user's supplied factory firmware, not a
claim of general redistribution permission. No calibration/full-flash/bootloader
image is added to this bundle. Kernel code and local C80 drivers retain GPL-2.0
licensing; GPL-2.0 and Linux-syscall-note text are supplied.

logs are retained only in the workspace, outside this deliverable.

# Аппаратный тест RAM32

Получен 21 октября 2026 года по времени Москвы от владельца Archer C80 v1 RU.
Версия ядра в отчёте: `6.12.113-c80-openwrt-ram32-cfg80211`.
Приведены результаты наблюдения владельца на физическом устройстве.
Сырые логи с идентификаторами клиента и платы сохраняются в личном архиве.

Штатный hostapd сообщил AP-ENABLED и AP-STA-CONNECTED. Через cfg80211/nl80211
`iw` показал AP C80-RAM32 на канале 6,2437 МГц,20 МГц без HT и одного
клиента с authorized/authenticated/associated=yes. Маршрут Windows к
192.168.2.1 проходил через Wi-Fi с исходным адресом192.168.2.2.

| Проверка Windows | Результат |
| --- | --- |
| Ping,32 байта | 20/20,0 потерь;4–28 мс,среднее10 мс |
| Ping с DF,payload1372 | 3/3,0 потерь;27–38 мс,среднее30 мс |
| TCP/22 через Wi-Fi | Доступен |

Штатная остановка дала AP-STA-DISCONNECTED и AP-DISABLED. Драйвер сообщил
starts/stops=1/1 и peer_adds/peer_deletes=1/1; итоговые result,primary,
cleanup,critical равны нулю. DMA idle,MCU stopped,STA delete и завершение
жизненного цикла ассоциации подтверждены.44 передачи данных получили
все44 подтверждения заголовка,токена и завершения; inflight=0,28 повторных
использований payload,ошибок ownership/early/duplicate/stale token нет.
По действующему контракту DMA-пулы остаются закреплены до reboot.
MemAvailable:7912 КиБ во время теста,8008 КиБ после остановки.

Строка `service delete … Not found` относится ко второму удалению уже
остановленной procd-службы из двух веток c80-wifi. В этом тесте она не
сопровождалась ошибкой AP/DMA/MCU cleanup. Для следующего независимого
выпуска отмечено исправление владения остановкой службы; выданный RAM32
не перепаковывается.

Этот тест подтверждает одну открытую сессию клиента и штатный stop.
WPA2,переподключение без reboot,несколько клиентов,предельная скорость
и полная UCI wifi up интеграция пока не реализованы либо не проверены.
Длительный тест5000 ping с оборотом колец и токенов относится к RAM31;
для RAM32 здесь выполнена короткая проверка нового управления AP.

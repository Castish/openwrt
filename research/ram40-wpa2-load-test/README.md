# Длительная проверка WPA2 на RAM40

**Длительная аппаратная проверка WPA2 на RAM40 пройдена:**
5000/5000 маленьких ping, 256/256 DF ping с нагрузкой 1372 байта и
89/89 последующих проверок связи — всего **5345/5345 без потерь**.
Windows подтвердил источник 192.168.2.2 через Wi-Fi, TCP/22 прошёл;
полное время сценария 252,091 с. Средние RTT: 9,82 / 23,25 / 9,99 мс.

Отчёт драйвера подтверждает 5385/5385 передач с возвратом всех токенов,
5369 повторных использований буферов, 42 оборота кольца и один оборот
пространства токенов. Encrypted TX/RX 5383/5409; replay, bad_crypto,
stale_tokens, ownership_fault и inflight равны нулю. AP работала
367,984477 с; остановка чистая, DMA/MCU остановлены, планировщик
восстановлен, MemAvailable 7760 KiB. Пул клиента сохраняется до reboot
по прежнему контракту. 11 повторных MAC-кадров и чужие кадры фильтровались;
они не означают потерь ICMP в этой проверке.

Это один прогон одного клиента. Повторное подключение здесь не выполнялось;
два WPA2-переподключения подтверждены предыдущим отдельным прогоном RAM40.
Точная версия PowerShell и интерактивная SSH-авторизация не представлены.
Образы RAM40 и исходники сценария сохранены без изменений.


Оставьте компьютер подключённым к C80-RAM40 с автоматическим IP. Распакуйте
архив в отдельную папку и выполните в Windows PowerShell из этой папки:

```powershell
.\c80-wifi-load.ps1
```

Тест занимает примерно четыре минуты: 5000 маленьких ping, 256 ping с
нагрузкой 1372 байта и DF, затем проверка сохранения связи и TCP/22.
Исходящий адрес должен быть 192.168.2.2, цель — 192.168.2.1. Если маршрут
сменится на другой интерфейс или подряд не пройдут десять запросов,
сценарий остановится и сохранит частичный результат. Единичные потери
учитываются; завершение теста само по себе не означает отсутствие потерь.

Результат c80-wifi-load-*.json появится рядом со сценарием. Пришлите его
содержимое или итоговый вывод PowerShell. Сценарий не меняет сетевые
настройки, не перезагружает роутер и не требует замены файлов TFTP.

После завершения, включая досрочную остановку, через SSH по LAN1 выполните
команды отдельно:

```sh
c80-wifi stop
c80-wifi status
c80-wifi report
```

Последнюю команду выполняйте после Finished в status. Сохраните полный
отчёт до перезагрузки. Повторный start AP в той же загрузке не поддерживается.

Это проверка устойчивости одного WPA2-клиента, а не максимальной скорости.
Исходники verifier/package включены для воспроизводимости; запускать их
на компьютере для аппаратного теста не требуется. Проверки управления
сценарием прошли в PowerShell 7.5.4 с синтетическими маршрутами/ответами/
часами. В облаке Windows PowerShell 5.1 не запускался. Позднее владелец успешно
выполнил физический Windows-тест; точная версия PowerShell не указана. Реальный .NET loopback в облаке не выполнен: в среде нет
системной утилиты ping, которая требуется реализации .NET на Linux.

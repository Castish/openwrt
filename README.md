# OpenWrt для TP-Link Archer C80 v1 RU / MT7626

Исходники исследовательского порта Archer C80 v1 RU (TP1900BN): ARM Cortex-A7,
MT7626 E2,4МиБ SPI NOR и **32МиБ RAM, подтверждённых загрузчиком**.
Репозиторий содержит наш код платы/драйверов, сборочные и проверочные скрипты,
патчи Linux и промежуточные исходные снимки разработки.

Подтверждено на устройстве: RAM-загрузка Linux/OpenWrt25.12.5, UART, чтение
и полный бэкап NOR, Ethernet/DSA и LAN1 SSH, программная перезагрузка,
автоматическая загрузка через модифицированный U-Boot, постоянные настройки
SSH, открытое Wi-Fi-подключение одного клиента с DHCP/ARP/ICMP/TCP.
RAM31 прошла5000 ping с одной потерей, ещё94 keepalive без потерь, с оборотом
TX-дескрипторов и токенов. Это не подтверждает WPA2, несколько клиентов,
полную скорость радио или готовность к установке OpenWrt во flash.

На устройстве проверена [RAM32](research/openwrt-ram32-cfg80211/) с
cfg80211/nl80211 и управлением открытой AP через штатный hostapd:
ассоциация клиента,20/20 обычных и3/3 DF ping, TCP/22 и штатная остановка
DMA/MCU прошли. [Результат аппаратного теста](research/openwrt-ram32-cfg80211/VALIDATION.md).
[RAM33](research/openwrt-ram33-reconnect/) подтвердила на плате 8 подключений
одного клиента, включая 7 повторных, при одном запуске AP. Обе показанные серии
ping прошли без потерь, остановка DMA/MCU завершилась без ошибок.
[Результат проверки](research/openwrt-ram33-reconnect/VALIDATION.md).
Подготовлена [RAM34](research/openwrt-ram34-wpa2/) с WPA2-PSK/CCMP через
штатный hostapd. На плате AP удалилась при последующей настройке сети ещё до
подключения клиента. [RAM35](research/openwrt-ram35-netup/) исправляет порядок
запуска: AP остаётся активной, но SSID на плате не найден. Остановка прошла
чисто. [RAM36](research/openwrt-ram36-beacon-diag/) сохраняет состояние маяка
до/после установки ключа и перед очисткой, исправляет блокировку отчётов.
На плате C80-RAM36 один раз появилась в поиске Wi-Fi, но после reboot
снова не была видна. [RAM37](research/openwrt-ram37-channel1/) подтвердила
канал1/2412MHz, но SSID также отсутствовал: счётчик маяков0 в снимке через
246,9секунды после GTK, stop чистый.
В [RAM38](research/openwrt-ram38-bmc-profile/) исправлено найденное отличие
пакета BMC от обычного заводского запуска AP: добавлен tag8, тело252байта.
Канал1 и порядок запуска сохранены. Программные проверки прошли; связь этого
отличия с видимостью и физическое подключение WPA2 ещё не подтверждены.

Git-история восстановлена из сохранённых исходных снимков. Каждый импорт
этапа оформлен отдельным новым коммитом и тегом `c80/<имя этапа>`; это не
первоначальные коммиты разработки. Исходные ZIP и личные образы сохранены
в закрытом рабочем архиве и не перепаковывались.

В Git нет заводских закрытых blobs, дампов/калибровки, персональных SSH-ключей
и готовых образов, которые содержат эти данные. Они подключаются локально.
Лицензии отдельных файлов указаны в SPDX/сохранённых LICENSE-файлах;
[подробности](docs/LICENSES.md). Это самостоятельный экспериментальный порт,
а не официальный образ OpenWrt для поддерживаемой модели.
